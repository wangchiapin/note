# 隨手貼

把複製的文字、圖片或用說的內容隨手貼進來，自動分類、可搜尋，登入後手機和電腦同步。個人用的小工具，不是教學遊戲。

🌐 **網址：** https://wangchiapin.github.io/note/

給 Claude：改這個工具前先讀這份。Ben 的規則：先討論、測好、問過才推（他說「推」才推）；用白話繁體中文說明。

## 功能

- **貼上**：文字貼進輸入框，或按「📋 貼上」。**圖片**：按「📷 圖片」選圖，會先壓縮（約 70 萬字元以內）再存，可替圖片加幾個字說明。
- **語音輸入**：按「🎤 語音」用說的輸入，預設中文（說西文會不準）。瀏覽器要支援語音辨識（Chrome、Edge、Safari）；不支援時可用手機鍵盤上的麥克風。
- **自動分類**：每一筆最多自動加 3 個標籤。內建分類：圖片、連結、聯絡方式、記帳、待辦提醒、教學、程式碼、其他。規則寫在 `index.html` 的 `classify()`。
- **自訂分類**：可新增、編輯、刪除分類（名稱最多 8 個字）。刪除分類不會刪掉已貼的內容，只是少了這個標籤。
- **分類規則**：頁面最下面的「分類規則」可以設「包含某個關鍵字就歸到某個分類」。
- **搜尋**：可搜文字、備註、標籤、時間。時間可以打「今天、昨天、本週、上週、本月、上個月、10/23、10月」，也可以和文字一起搜（例如「今天 連結」），或用 📅 選日期範圍。
- **備註**：每一筆可以加或編輯備註。
- **刪除**：每一筆可單獨刪除（會先確認）。

## 同步與資料

- 用 Google 登入後，資料存在 Firebase Firestore（專案 `perrito-busca-el-tesoro`，路徑 `users/{uid}/clips`；分類規則等設定存在同一處的 `__settings__`），手機和電腦即時同步。
- 不登入也能用，只是只存在這台裝置的瀏覽器（localStorage）。
- Firebase 設定已固定寫在程式裡，沒有「進階設定」。登入失敗時，通常是網站網域沒有加進 Firebase 的授權網域。
